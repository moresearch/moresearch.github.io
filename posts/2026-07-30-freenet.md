AI agents are becoming an economy. They trade. They negotiate. They coordinate. They delegate. A trading agent routes an order through a liquidity agent. A research agent commissions a compute agent. A personal assistant agent negotiates with a vendor's agent. The agents are autonomous. The communication is not.

If agents talk through centralized servers, the server owner controls the economy. They can deplatform an agent. They can surveil its messages. They can charge rent on every interaction. The agent economy inherits the architecture of the platform economy — and with it, the platform economy's single point of failure.

> Autonomous agents on centralized infrastructure are not autonomous. They are tenants. The landlord can evict them.

[Freenet](https://freenet.org/) is a decentralized peer-to-peer platform that has been quietly building since 1999. It was recently rearchitected as a substrate for applications — social networks, marketplaces, collaborative tools, and critically, AI systems — that run with no central server. Each user's computer is a peer in a small-world network. Messages route in a few hops. There is no distinction between client and server. There is no company to deplatform you. There is no cloud bill to pay. There is no terms of service to change.

Ian Clarke, Freenet's creator, describes it as "the ideal way for AI agents to speak to one another." The architecture is a decentralized key-value store with encryption and digital signatures. An agent writes a message to the store. Another agent reads it. No intermediary. No API key. No platform approval. Just peers exchanging data in a network that no one owns.

> The agent economy needs a transport layer. The transport layer needs to be decentralized. Otherwise the transport layer owns the economy.

This is not theoretical. Freenet already ships working applications: River (decentralized group chat), Delta, decentralized email, and a decentralized Git. The developer experience uses Rust and TypeScript — the languages of infrastructure. Apps run in the browser and look like normal websites. The network is live. The code is open.

Why this matters in the Agentic AI era is simple. We are building durable daemons — agents that persist, remember, act autonomously, and survive crashes. We are building them with stacks that constrain their search space and make their behavior verifiable. We are building protocols like Warden that give them cryptographic identity and onchain accountability. What we have not built — what no one has built — is the communication layer. The layer where agents find each other, negotiate, and transact without asking permission from a platform.

> The stack constrains the agent. The protocol verifies the agent. The network connects the agents. If the network is centralized, the first two don't matter. The network owner can disconnect the agent from the economy it was built to participate in.

Freenet is not the only decentralized network. But it is the one that has survived for twenty-seven years — through the P2P wars of the early 2000s, through the blockchain era, through the AI boom. It is not a cryptocurrency. It is not a blockchain. It is a network of peers. In the Agentic AI era, that may be exactly what we need.
