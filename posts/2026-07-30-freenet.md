The AI agent buzz is deafening. Every company is shipping an agent SDK. Every conference is about agentic workflows. Every VC deck has a slide about autonomous AI. And every single one of those agents will talk to other agents through centralized infrastructure — an API gateway owned by a company, a cloud function that can be turned off, a platform that can change its pricing or its terms or its mind.

> The buzz is about autonomy. The infrastructure is about dependence. The contradiction is the interesting part.

[Freenet](https://freenet.org/) is a decentralized peer-to-peer network that has been quietly running since 1999. It was recently rearchitected — not as a blockchain, not as a cryptocurrency, but as a platform for applications that run with no central server. Each peer is a node. Messages route through a small-world network in a few hops. There is no company. No cloud bill. No terms of service. No API key to revoke.

Ian Clarke, Freenet's creator, describes it as "the ideal way for AI agents to speak to one another." The architecture is a decentralized key-value store with encryption and digital signatures. An agent writes a message. Another agent reads it. No intermediary. No platform approval. Just peers.

> Every AI startup is building agents on AWS, on OpenAI's API, on Anthropic's API. Freenet is the choice that says: what if the agents talked to each other directly, and no one owned the wires?

This is not a whitepaper. Freenet ships working apps: River (decentralized group chat that feels like Signal), decentralized email, decentralized Git. Developers build in Rust and TypeScript. Apps run in the browser. The network is live.

Why this is interesting now, specifically, is that we are building an agent economy without thinking about who owns the communication layer. Warden gives agents cryptographic identity. Durable daemons give them persistence and verifiable execution. Stacks constrain their search space. But none of these answer the question: when two agents from different companies need to negotiate, whose server do they meet on? If the answer is "OpenAI's" or "Google's" or "AWS's," the agent economy has a landlord. The landlord collects rent. The landlord can evict.

> The stack constrains the agent. The protocol verifies the agent. The network connects the agents. If the network is centralized, the first two are ornamental.

Freenet is not the obvious choice. It has no marketing budget. It has no conference booth. It has no venture backing. It has survived for twenty-seven years — through the P2P wars, through the blockchain era, through the AI boom — as a nonprofit run by a small team. It is the least buzzy infrastructure in the most buzzy sector. That is what makes it worth paying attention to. The buzz will fade. The network will still be there.
